# Research on the Alpöge–Claude RH/Dirichlet GRH formalization

Independent extraction and testing of selected reusable lemmas from the publicly released Lean formalization. This repository is **not** a replacement proof of RH or GRH.

Research work is proposed on topic branches and reviewed before merging. Source material: [community mirror](https://github.com/leanprover-community/riemann-hypothesis), [statement catalogue and graph](https://andrewodesky.com/rh/), and [MIT audit](https://math.mit.edu/~drew/grh/).

No mathematical claim is classified as formally proved until Lean compilation, statement fidelity and axiom checks are recorded.
